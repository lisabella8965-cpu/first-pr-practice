# first-pr-practice

A tiny Python utility for basic word statistics, used as a sandbox for
practicing the GitHub pull request workflow.

## Functions

- `count_words(text)` — returns the number of whitespace-separated words.
- `longest_word(text)` — returns the longest word in the text.

## Usage

```bash
python word_stats.py
```

## Tests

Run the test suite with:

```bash
python -m pytest
```
